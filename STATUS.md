# Port status

One line per exported Math::Prime::Util 0.75 function (428 names, from `@EXPORT_OK` in `Util.pm`; same list as the Rust port's STATUS.md).
Format: `- [ ] mpu_name -> Ada_Name`. Ticks: `[ ]` todo, `[x]` done, `[-]` not applicable in Ada (note why).
Ada_Name is the default Ada_Case form; the child package that holds it is set in PLAN.md section 5 and recorded here when the first one lands.
Ticks are generated by `tools/status.py` (to be written in phase 0) from the subprogram names in `src/`; do not edit by hand once it exists.
